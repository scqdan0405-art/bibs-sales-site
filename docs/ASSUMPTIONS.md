# 仮定事項

| 仮定内容 | 理由 | 影響範囲 | 後から変更する方法 |
|---|---|---|---|
| 初期版の実行DBはJSON永続化とし、正式DB移行用SQLを同梱する | 依存追加なしで短時間に起動可能にするため | データ保存層 | `src/lib/store.ts` をDBアダプタへ差し替え、`prisma/migrations/001_initial.sql` を適用 |
| 商品カテゴリはビブス販売を想定する | プロジェクト名と仕様の販売サイト要件に合わせるため | 表示文言、初期データ | 管理画面のサイト設定、価格、FAQ、事例から変更 |
| メール送信は初期版ではアウトボックス保存とする | SMTP/API秘密情報が未提供のため | メール通知 | `MailAdapter` をSMTP/API実装へ差し替え |
| 会社名、営業時間、送料、納期、キャンセル条件は仮文言 | 正式情報が未提供のため | 公開ページ、フッター、注意事項 | 管理画面または初期データで変更 |

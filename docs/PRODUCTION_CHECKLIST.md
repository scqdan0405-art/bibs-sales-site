# 本番公開前チェックリスト

- 正式ロゴと商品画像へ差し替えた
- 商品説明、価格、税込/税別、送料、納期を確認した
- キャンセル、修正、返品条件を確認した
- 会社名、運営者情報、営業時間を確認した
- プライバシーポリシーを確認した
- 通知先メール、From、Reply-To、SPF/DKIM/DMARCを設定した
- 本番ドメイン、DNS、SSL、HSTSを設定した
- 管理者パスワードを変更した
- `.env` がGitへ登録されていない
- DB、ストレージ、メール、解析を本番用へ分離した
- 添付保存先がWeb公開外である
- バックアップ取得と復元手順を確認した
- スマートフォン実機で表示と問い合わせを確認した
- 404、500、robots、sitemapを確認した
